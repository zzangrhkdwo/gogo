# 닷지 (dodge) — v49 (만듦)
옛날 곰플레이어에 숨어 있던 '닷지(총알 피하기)'처럼 — 사방에서 날아오는 총알을 **내 아바타**로 피해 오래 버티기.

## 하는 법
- 혼자: 방향키 또는 WASD. 휴대폰은 화면을 끌어서 이동.
- 한 기기 둘이서: 1P = WASD, 2P = 방향키. 휴대폰은 화면 왼쪽 반 = 1P, 오른쪽 반 = 2P.
- 온라인 둘이서: 방 코드로 들어와 방장이 [시작].
- 둘이서·온라인 **방식** (대결 화면의 '방식' 줄): **협동** = 둘이 같이 버티기, 한 명이라도 맞으면 바로 끝 / **대결** = 먼저 맞는 사람이 짐 (같이 맞으면 무승부).
- 시작 전 2초 준비. P·Esc = 일시정지 (온라인 제외).

## 규칙 (원래 닷지처럼)
- 총알은 화면 네 가장자리에서 나를(둘이면 살아 있는 사람 중 하나를) 노리고 날아옴. 조금씩 빗나감(±0.22).
- 원래 닷지보다 어렵게 (선생님 요청): 처음 12발 → 1초마다 **2발**씩 늘어남 (최대 220). 빠르기 100~165 에서 시작해 1초마다 **+1.5%** (30초 1.45배 · 60초 1.9배 · 최대 2.2배). 숫자는 settings.js 에서 조절.
- 점수 = 버틴 시간 (0.01초). 랭킹 = 가장 오래 버틴 시간 (혼자 · 온라인).
- 포인트: 10초 +1P · 30초 +2P · 60초 +3P (혼자 · 온라인 협동) · 온라인 대결 승리 +2P. 한 기기 둘이서는 기록만.

## 온라인 구조
- 방장 기기가 총알을 계산해서 초당 10번 보냄. 손님은 자기 아바타를 직접 움직이고(0.05초마다 자리 보냄), 자기 화면 총알에 맞았는지 직접 판단해 'hit' 을 보냄 → 방장이 끝을 정해 'end' 를 보냄.
- 대결 화면의 '방식'은 `js/app.js` 의 v49 새 기능 `subModes` (settings.js 에 적으면 어느 게임이든 '방식' 줄이 생김 · 온라인은 방장이 고르고 start 메시지에 sub 로 감).
