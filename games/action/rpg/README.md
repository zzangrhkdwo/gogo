| 8 하늘섬 마을 | 71~80 | Lv.71~80 | 벚꽃·구름 바위 | 폭풍 거인 |
| 9 **불꽃왕성** (성) | 81~90 | **Lv.82~100 (2씩)** | 용암·검은 바위 | 마왕 용 |

- 마을 1~8 은 마을 하나에 10레벨, 사냥터마다 권장 레벨 +1. 마지막 마을(불꽃왕성)은 80 → 100, 사냥터마다 +2.
- 권장 레벨 계산: `data.js` 의 `recOf(지역, 몇 번째)`. 지역마다 범위는 `LV_RANGE`.
- 지도 오른쪽 끝 = 다음 지도, 왼쪽 끝 = 이전 지도.
- 사냥터 10번째(10·20·…·90)는 **보스** 지도 (보스 1 + 부하 6, 보스는 60초 뒤 다시 나옴, 장비를 꼭 떨어뜨림).
- 몬스터 성질: `calm` 먼저 안 때림 · `aggro` 가까이 가면 달려옴 · `shoot` 멀리서 쏨 · `boss` 큰 원 공격(빨간 원 예고 0.9초).
- 몬스터가 나보다 높으면 내 피해 ↓·받는 피해 ↑, 10레벨 넘게 낮은 몬스터는 경험치 20%만.
- 지도 그림은 최근 4장만 기억 (사냥터 1장 ≈ 7MB, 90장을 다 들고 있지 않게). 다시 들어가면 같은 모양으로 다시 그림.

## 캐릭터 · 직업 · 마법
- 직업 없음. 마법을 배우는 레벨에 따라 파는 마을이 정해짐 (Lv1~10 마을1 … Lv71~80 마을8, Lv81~100 마을9). 레벨이 오르면 능력치(공격·마력·방어·체력·마나)가 오르고, 마법 학교에서 새 마법을 삼.
- 마법 칸 4개 (1~4 키). 마법 창(K)에서 칸에 넣기.
- 마법 종류(kind): `bolt` 탄 · `nova` 주변 폭발 · `beam` 일직선 · `rain` 여러 곳에 떨어짐 · `pool` 바닥 장판 · `dash` 돌진 · `heal` 회복 · `shield` 보호막.
- 원소 효과: 불=화상(계속 피해) · 물=느려짐 · 바람=밀어내기 · 땅=큰 피해(×1.2) · 번개=기절 · 빛=흡수 회복.
- **융합**: 원소 짝 15가지(불+물=증기 폭발 …). 위력 = 두 재료 위력 합 × 0.85, 마나 = 합 × 0.75, 레벨 = 높은 쪽. 이름 뒤 Ⅱ~Ⅴ 는 재료 레벨 구간.
- ※ **지금 마법 25개·융합표는 임시**입니다. skillcom 폴더를 연결하면 `data.js` 의 `SK`·`FUSION` 표를 skillcom 마법으로 바꿉니다. (game.js 는 kind 8종류만 알면 되므로 표만 바꾸면 됨)

## 장비 (아바타 위에 겹쳐 입기)
- 부위 5개: 무기(검/지팡이) · 투구 · 갑옷 · 신발 · 장신구(반지).
- 단계 9개(가죽·청동·이끼 나무·철·강철·얼음 수정·자수정·하늘 깃털·불꽃 용 — 마을 하나에 하나) × 보통/정예 → 그 지역 사냥터에서 떨어짐. 착용 레벨: 보통 = 지역 첫 레벨, 정예 = 지역 중간(마을9 는 81·91). 정예는 사냥터 6~10번에서만.
- 입으면 **아바타 그림 위에 장비가 그려짐** (아바타 옷은 그대로 두고 위에 덧입는 방식).
- 가방 창 **'장비 안보이기'** 를 켜면 장비 그림만 숨기고 **능력치는 그대로**.
- 지팡이를 들면 기본 공격이 짧은 마법탄(공격 60% + 마력 50%).

- **파일**: `net.js`(연결) · `supabase/rpg_online_v42.sql`(서버 인원 표 `rpg_online` + 함수 `rpg_servers`·`rpg_join`·`rpg_leave`, **한 번 Run**) · `settings.js` 의 `online: { servers: 10, cap: 30, pingSec: 15 }`.
- **들어가기**: 로그인한 사람은 게임을 열면 '서버 고르기' 창 (아래 '서버' 버튼으로 언제든 옮기기). 서버마다 인원 막대·여유/보통/혼잡/가득, 가장 한산한 서버에 '추천', **'가장 한산한 서버로 들어가기'** 버튼 → 한쪽으로 쏠리지 않게. 30명이면 그 서버는 못 들어감(서버에서 잠금하고 셈, 동시에 들어와도 안 넘침). 손님은 혼자 하기.
- **보이는 것**: 같은 서버 + 같은 지도(건물 안 포함)에 있는 사람 — 아바타·장비·닉네임(하늘색)·레벨, 걷는 모습, 마법 효과(그림만, 피해 없음), 작은 지도의 하늘색 점, 위 가운데 'N서버 · 여기 n명'. 몬스터·떨어진 물건은 각자 따로.
- **저장**: 레벨·아이템·마법·장비는 서버와 상관없이 **계정(game_saves)** 하나 → 어느 서버로 옮겨도 그대로. 장비를 얻거나 입으면 몇 초 안에 서버 저장, 서버를 옮기기 직전에도 저장.
- **자리 유지**: 15초마다 `rpg_join` 을 다시 부름(지금 지도·레벨도 기록). 45초 넘게 소식이 없으면 인원에서 빠짐. 창을 닫거나 '혼자 하기'를 누르면 `rpg_leave`.
- **무료 요금제 아끼기** (Supabase Realtime 무료: 동시 연결 200 · 초당 메시지 100): 지도마다 따로 채널(`rpg-<서버>-<지도>`), 같은 지도에 아무도 없으면 안 보냄, 가만히 있으면 안 보냄, 움직일 때 0.3~1.2초마다(사람이 많을수록 드물게) 위치+속도를 보내고 받는 쪽이 속도로 앞질러 그림. 서버 인원은 실시간 연결이 아니라 DB 함수로 셈.
  - ※ 서버 10개 × 30명 = 300명은 무료 요금제의 동시 연결 200개보다 많음. 실제로 200명 넘게 동시에 접속하려면 Supabase Pro 가 필요.
- **체험 모드**(Supabase 없음): 같은 브라우저의 다른 탭끼리 연결 (시험용). 시험 스크립트 `작업도구\테스트\rpg\net2.js`(두 탭: 서로 보임·움직임·건물 안·마법 효과·서버 옮기기).
