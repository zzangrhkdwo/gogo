# games — 게임 폴더

장르별 폴더 안에 게임마다 폴더가 하나씩 있습니다.

```
games/

├─ puzzle/            퍼즐
│  ├─ battle/         블록 대전 (실시간 개인전·팀전)
│  ├─ blocks/         블록 쌓기
│  └─ 2048/           2048
├─ arcade/            아케이드
│  ├─ snake/          스네이크
│  └─ dodge/          닷지 (총알 피하기 · 혼자/둘이서/온라인 · 협동·대결, v49)
├─ board/             보드게임
│  ├─ baduk/          바둑 (9줄)
│  ├─ omok/           오목
│  ├─ janggi/         장기
│  ├─ chess/          체스
│  ├─ alkkagi/        장기 알까기
│  └─ code/           숫자 코드 (다빈치 코드 방식)
├─ action/            액션
│  ├─ mecha/          메카 대전
│  └─ rpg/            마법 융합 모험 (도트 RPG · 마을 9 · v40)
└─ shooting/          슈팅
   └─ sky/            6.25. 하늘 (세로 비행기 슈팅, 10스테이지 · 혼자/둘이서/온라인 협동)
```

## 게임 폴더 하나의 구성
| 파일 | 내용 |
|---|---|
| `game.js` | 게임 본체 |
| `settings.js` | **포인트·승리 조건·배경음악·소개 문구** ← 밸런스 조정은 여기만 |
| `bgm/` | 배경음악 파일을 넣는 곳 (`bgm.mp3`) |
| `README.md` | 이 게임의 규칙 정리 |

## 포인트 규칙 (현재 값 · 밸런스 조정 예정)
| 게임 | 승리 조건 | 승리 | 패배 |
|---|---|---|---|
| 블록 대전 | 개인전 1위 / 팀전 이긴 팀 | +2P (컴퓨터만 상대면 +1P) | -1P |
| 블록 쌓기 | 한 판에 20줄 이상 | +2P | -1P |
| 2048 | 512 타일 만들기 | +2P | -1P |
| 스네이크 | 사과 10개 이상 | +2P | -1P |
| 바둑 · 오목 · 장기 · 체스 · 알까기 · 숫자 코드 | 컴퓨터에게 승리 (둘이서 한 판은 포인트 없음) | +2P | -1P (무승부 0P) |
| 6.25. 하늘 | 스테이지를 깰 때마다 (혼자·온라인) | 스테이지당 +1P (최대 +10P) | 0P |

- 보유 포인트는 **0P 아래로 내려가지 않습니다.**
- 서버 안전장치로 한 판에 **±10P 까지만** 인정됩니다. (더 크게 하려면 `supabase/schema.sql`의 숫자 10 수정)
- 레벨은 '지금까지 얻은 포인트'로 정해져서, 상점에서 포인트를 써도 레벨은 내려가지 않습니다.

## 새 게임 추가하는 법
1. 장르 폴더 안에 새 폴더를 만듭니다. 예: `games/action/breakout/`
2. 다른 게임 폴더의 `settings.js`, `README.md`, `bgm/`을 복사해서 이름·규칙을 고칩니다. (`id`, `folder`, `category`)
3. `game.js`를 만듭니다. (스네이크 `game.js`가 가장 짧은 예시)
4. `index.html` 아래쪽 `<script>` 목록과 `sw.js`의 `SHELL` 목록에 두 파일을 추가하고, `sw.js`의 `VERSION` 숫자를 올립니다.
5. 게임 목록·랭킹·전적·포인트는 자동으로 연결됩니다. (DB 수정 필요 없음)

### 대결 화면(`board: true`)에서 점수로 랭킹을 매기는 게임 (v38, 6.25. 하늘)
- `scoreRank: true` → 끝날 때 `onOver({ win, score, points, title, message })` 의 `score`·`points` 를 그대로 저장 (한 기기 둘이서는 기록만)
- 화면 글자 바꾸기: `aiLabel`('AI 대전' 대신, 예: '혼자') · `onlineBtn` · `resignLabel`('기권' 대신) · `rankSub`(랭킹 제목 옆) · `noteText(mode)` · `cardRules()`
