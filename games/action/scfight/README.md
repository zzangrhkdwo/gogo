# Skillcom Fight (3D 마법 대결) — v45 첫 버전 (2026-10-31)

skillcom RPG 에서 키운 캐릭터(**아바타 + 레벨만**, 장비 X)로 겨루는 3D 1:1 마법 대결.

## 파일
| 파일 | 내용 |
|---|---|
| `settings.js` | 이름·조작·레벨 가져올 게임(`levelFrom: 'rpg'`)·레벨당 스탯(2)·스탯 최대(50)·이기면 포인트 |

## 화면
- **대기방**(왼쪽): 내 캐릭터(RPG 레벨·체력·전적) · **Skillcom 컴퓨터와 대결** · **온라인 1:1 방 만들기** · 열린 방 목록(들어가기). 로그인 화면·캐릭터 선택 화면은 없음.
- **스킬 고르기**(오른쪽 위): 원소 6개(화염·냉기·번개·땅·암흑·빛) 중 4개를 눌러 1~4 칸에.
- **스탯**(스킬 아래): 레벨당 2포인트, 스탯마다 최대 50, 다시 나누기 무료. 힘(피해 +2%) · 민첩(이동 +1%) · 지혜(마나 회복 +4%) · 체력(최대 체력 +2%) · 화염/냉기/번개/땅/암흑/빛 저항(그 원소 피해 −1%).

## 대결
- 마법은 **차지 → 발사**: 숫자 1 = 1번 마법 차지(발사 대기). **차지 중에 숫자를 하나 더** 누르면 융합 차지 — 같은 숫자(1+1)는 강화 융합(한 발, 큼), 다른 숫자(1+2)는 융합 3발. 이름 21개(`FU` 표).
  **마우스 왼쪽 = 발사, 오른쪽 = 차지 취소**. 융합 차지 중에 숫자를 또 누르면 그 숫자로 새로 차지. 재사용 대기 중이면 발사가 안 되고 차지는 유지. 휴대폰은 차지 중에 오른쪽에 [발사]·[취소] 버튼이 나옴.
- **V 키 / 오른쪽 위 버튼 = 1인칭 ↔ 3인칭** (배틀그라운드처럼). 마지막 시점을 기억함.
- WASD 이동 · Space 점프 · 화면을 누르면 마우스 고정(둘러보기, Esc 로 풀기). 휴대폰: 왼쪽 끌기 = 이동, 오른쪽 끌기 = 둘러보기.
- 원소 특징: 화염 = 불탐(2초) · 냉기 = 느려짐 · 번개 = 가장 빠름 · 땅 = 가장 셈 · 암흑 = 살짝 따라감 · 빛 = 맞히면 내 체력 회복.
- 체력 = (100 + 레벨×9) × (1 + 체력 스탯×2%), 마나 100, 피해 × (1 + 레벨×2.5%) × (1 + 힘×2%) × (1 − 저항%).
- **컴퓨터 상대**: 내 레벨과 같은 레벨, 스킬 4개 무작위, 거리를 두고 옆으로 움직이며 내가 움직이는 쪽을 앞질러 쏨.
- **온라인 1:1**: `Hub.channel('scf-lobby')`(방 목록) · `'scf-room-<코드>'`. 0.08초마다 위치·체력, 마법은 쓸 때 보냄. **맞았는지는 맞은 사람 쪽에서 계산**(내 체력은 내가 정함). 상대가 나가면 승리.
- 이기면 +1P(로그인), 랭킹 = 승리 수.

## v45 — 1:1 · 2:2 대결 (10/31 저녁)
- **컴퓨터와 대결**: 대기방에서 [1:1]·[2:2] 를 고르고 난이도를 누름. 2:2 = 나 + 내 편 '조선 장수'(보통) vs 상대 장수 2명(고른 난이도). 고른 방식은 저장됨(`S.mode`).
- **온라인 방**: [1:1 방] (2명이 되면 바로 시작) · [2:2 방] (**바로 시작 안 함**). 방 목록에 `1:1`/`2:2`·인원(2/4) 표시, 가득 찬 방은 못 들어감.
- 2:2 방은 **청군·홍군** 두 칸으로 보임. 들어오면 사람이 적은 편으로 자동 배정, [청군으로 옮기기]/[홍군으로 옮기기] 로 바꿈(한 편 최대 2명). 방장이 [시작] (2명 이상) → 빈자리는 컴퓨터. 동시에 들어와 한 편이 3명이 되면 늦게 온 사람이 자동으로 옮김.
- 방장이 각자 고른 편대로 `start` 메시지(편 나눔)를 보냄. 빈자리 컴퓨터는 방장 기기가 움직이고 체력을 정함. 끝 화면: "청군 승리!"
- 같은 편 마법은 **안 맞음**. 머리 위 이름표: 파란 = 같은 편, 주황 = 상대. 왼쪽 위 = 내 체력 + 같은 편 체력, 오른쪽 위 = 상대 체력.
- 내가 먼저 쓰러지면 같은 편을 따라 보며 응원. **한 편이 모두 쓰러지면 끝** (같은 편이 이기면 나도 승리).
- 나간 사람: 방에서 빠지고 5초 넘게 소식이 없으면 쓰러진 것으로 침 (방장이 나가면 방장이 맡은 컴퓨터도).
- 보내는 양: 기기마다 자기 몸(방장은 컴퓨터 포함)을 한 메시지로 묶어 1:1 은 0.08초, 2:2 는 0.12초마다.
- 시험: `작업도구/테스트/rpg/scf22.js` (컴퓨터 2:2 · 온라인 2:2 세 탭 + 컴퓨터 1, 같은 편 안 맞음 확인)
