# 하늘 편대 (sky) — v38 (만듦)

선생님 요청(2026-10-30): 예전 오락실의 세로 비행기 슈팅처럼, **스테이지 10단계**, **스테이지마다 보스**, **스테이지가 올라갈수록 총알이 빨라지게**, **오프라인·온라인 친구와 최대 2인**.
(원작의 이름·그림은 쓰지 않고 방식만 참고. 비행기·적·보스·배경은 모두 코드로 그린 도트 그림)

## 방식
| 항목 | 내용 |
|---|---|
| 모드 | 혼자(쉬움·보통·어려움) · 한 기기 둘이서(협동) · 온라인 다른 기기 친구와 둘이서(협동) |
| 이동 | W A S D 또는 방향키. **총알은 저절로 나감** (휴대폰: 화면을 끌면 그만큼 이동, 손가락이 비행기를 가리지 않음) |
| 폭탄 | 스페이스 · G · B (휴대폰: 오른쪽 아래 '폭탄'). 화면의 적 총알을 모두 지우고 적에게 큰 피해, 잠깐 무적 |
| 한 기기 2P | 1P = W A S D + G(폭탄) / 2P = 방향키 + 엔터(폭탄, 숫자패드 0 · / · 오른쪽 Shift 도 됨) |
| 일시정지 | P 또는 Esc, 오른쪽 '일시정지 / 계속' 버튼 (온라인은 없음) |
| 맞음 | 가운데 흰 점이 맞는 곳(작게). 맞으면 목숨 -1, 파워 -1(P 아이템이 떨어짐), 2.5초 무적. 목숨: 쉬움 5 · 보통 3 · 어려움 3 |
| 아이템 | P 파워(4단계까지, 넘치면 +1000점) · B 폭탄 · ★ +500점. 주황 편대를 모두 잡거나 폭격기·대형기를 잡으면 나옴 |
| 끝 | 10스테이지 보스를 무찌르면 '모두 클리어!'. 둘이서는 **둘 다** 목숨이 떨어지면 끝 (목숨을 다 쓴 친구는 다음 스테이지에서 목숨 1개로 부활) |
| 포인트 | 스테이지를 깰 때마다 +1P (10개 모두 = +10P, 혼자·온라인). 한 기기 둘이서는 기록만 |
| 랭킹 | **내 점수**(적을 맞힌 사람이 점수를 받음). 홈·게임 화면의 '최고 점수 TOP 10' |

- 보스 체력이 절반 아래로 내려가면 공격이 1.25배 빨라지고, 6스테이지부터는 공격 두 가지를 함께 씀.
- **총알 빠르기** = `bulletBase`(140) × (1 + `bulletStep`(0.12) × (스테이지 − 1)) × 난이도 배율(쉬움 0.85 · 보통 1 · 어려움 1.15). 10스테이지는 1스테이지의 약 2.1배. 스테이지 시작할 때 '적 총알 속도 ×1.36' 처럼 화면에 보여 줌.
- 보스가 나오기 전 시간 = `waveSec`(40) + 스테이지 × 2초. 적 체력은 스테이지마다 +12%, 둘이서는 1.35배(보스 1.4배).
- 점수: 작은 적 100~200 · 배 300 · 폭격기 800 · 대형기 3000 · 보스에 맞힐 때마다 10 · 보스 무찌름 3000×스테이지(모두) · 스테이지 클리어 1000×스테이지(살아 있는 사람).

## 온라인 (협동)
- 방장 기기가 적·총알·아이템·점수를 계산하고 0.1초마다 보냄. 손님 기기는 받은 총알을 속도대로 이어서 움직여 그림.
- **손님 비행기는 손님 기기가 직접 움직이고(0.05초마다 자리 보냄), 자기 화면에 보이는 총알에 맞았는지도 손님 기기가 판단**해서 방장에게 알림 → 인터넷이 조금 느려도 억울하게 맞지 않음.
- 내 총알 그림은 각 기기가 그림(실제 맞히기·점수는 방장). 폭탄은 손님이 누르면 방장에게 보내서 터뜨림.
- 손님이 나가면 방장 혼자 계속, 방장이 나가면 손님 쪽은 끝. 손님이 '그만하기'를 누르면 손님만 끝나고 방장은 계속.
